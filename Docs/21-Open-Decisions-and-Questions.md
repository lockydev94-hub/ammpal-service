## 1. Purpose & Rules

This registry tracks every question that a document had to defer. It exists so that ambiguity is
**surfaced and owned**, never silently resolved.

| Rule | Detail |
|---|---|
| DEC-01 | A question appears here the moment a document needs an answer it does not have. |
| DEC-02 | Every question has a single owner, a deadline, and a recommended answer. |
| DEC-03 | A question is closed only by an explicit recorded decision — never by silence. |
| DEC-04 | When a decision changes a rule, the affected documents are updated in the same change and the entry moves to §10 (Change Log). |
| DEC-07 | When an audit finds two documents asserting incompatible rules, **neither is edited into the other**. The conflict is registered as an `OD-DOC-nn` row in §7 with both citations, and both documents are annotated as `[OPEN]` on that point until the owner decides. |
| DEC-05 | A question past its deadline without a decision is escalated to the founder. |
| DEC-06 | `[BLOCKER]` items gate the phase named in the deadline column. |

**Severity**

| Tag | Meaning |
|---|---|
| `[BLOCKER]` | The phase cannot start or ship without the answer |
| `[IMPORTANT]` | Affects design; a default is assumed if the deadline passes |
| `[NICE]` | Can be deferred to a later phase |
